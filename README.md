# @agentpay/agent-cost-tracker-mcp

Track AI agent token usage and API costs

This npm package wraps the Python MCP server at [Rumblingb/agent-cost-tracker-mcp](https://github.com/Rumblingb/agent-cost-tracker-mcp).

## Install

```bash
npm install -g @agentpay/agent-cost-tracker-mcp
pip install mcp
```
pip install tiktoken

## Usage

```json
{
  "mcpServers": {
    "agent-cost-tracker-mcp": {
      "command": "npx",
      "args": ["@agentpay/agent-cost-tracker-mcp"]
    }
  }
}
```
